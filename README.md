# Test Maker — 한글 시험지 만들기

문항은 **서식 없이** JSON으로 적고, 출력할 때 **학교 시험지 양식의 스타일**로 바꿔 한글(.hwp/.hwpx)·PDF를 만듭니다.
학생용과 **원안지(정답 형광펜)**를 함께 만들고, 정답·해설지도 만들 수 있습니다.

- 필요한 것: Windows, 한컴오피스 한글(2024 Edu에서 확인), .NET 10 SDK
- 한글을 화면에 띄우지 않고 뒤에서 조작합니다. **실행 중에는 한글 창을 모두 닫아 두세요**(작업 중인 문서 보호를 위해 멈춥니다).

## 빠른 사용법

```powershell
dotnet build

# 1) 학교 양식 학습: 첫 파일 = 학교 양식(견본), --also = 실제로 낸 시험지(실제 사용 방식)
dotnet run --project src/TestMaker.Cli -- learn "시험출제원안지(양식, 3학년).hwp" forms/우리학교 --also "작년 2학기 1차.hwp"

# 2) 시험 JSON 만들기(예시에서 시작) → 검사
dotnet run --project src/TestMaker.Cli -- sample 기말고사.json
dotnet run --project src/TestMaker.Cli -- check 기말고사.json

# 3) 출력: 기말고사.hwp(학생용) + 기말고사_원안지.hwp(정답 형광펜) [+PDF, +정답지]
dotnet run --project src/TestMaker.Cli -- render 기말고사.json -t forms/우리학교 --pdf --answers
```

## 양식을 어떻게 소화하나

학교 시험지 양식은 크게 둘입니다.

| | 완성형 | 무질서형 |
|---|---|---|
| 문항 번호 | 스타일의 개요/문단번호(엔터 치면 번호) | 글자로 "1." 입력 |
| 이 앱의 처리 | 학교 스타일·번호 체계를 그대로 연결 | 학습한 모양으로 문단을 만들고 번호는 학교 형식으로 입력 |

어느 쪽이든 **학교 문서의 견본을 복제**해서 만듭니다. 그래서 학교 스타일, 개요 번호, 탭 위치, `<보 기>` 상자 모양이 그대로 나오고,
문항 순서를 바꾸면 번호가 따라 바뀌며, 스타일을 고치면 전체가 함께 바뀝니다(마지막 손질이 쉬움).

`learn`이 배우는 것:
- **머리·꼬리**: 1번 문항 앞(결재란, 제목 상자, 유의사항…)과 맨 끝(확인 사항 상자), 머리말·꼬리말을 원본 그대로
- **채울 칸 자동 인식**: 색 글씨 칸과 흔한 형식 → `{{제목}}` `{{일시}}` `{{과목}}` `{{쪽수}}` `{{문항수}}` 등으로 바꿔 두고, 출력할 때 채움
- **역할별 스타일**: 발문(번호) / 이어지는 발문(그림·자료 뒤, 번호 없음) / 묶음 머리 `[3∼4]` / 그림 / 빈 줄
- **선택지 배치 견본**: 1행·2행(3+2)·3행(2+2+1)·5행. 길이에 맞는 배치를 고릅니다.
  5행은 **개요 자동번호**, 나머지는 **원문자 직접 입력 + 학교 탭 간격**(학교 관행)
- **상자 견본**: `<보기>`(줄 머리 ㄱ.ㄴ.ㄷ.이 자동이면 그대로), 자료 상자
- **실제 사용 방식**(`--also`): 문항 사이 빈 줄 수, 양식 파일과 실제 시험지가 다를 때 실제로 많이 쓴 스타일

학습 결과는 양식 폴더(`form.json`, `base.hwpx`, `boxes.xml`)에 저장됩니다. `form.json`은 직접 고쳐도 됩니다.

## 문항 JSON

```jsonc
{
  "info": { "title": "2025학년도 2학기 2차 지필평가", "subject": "과학", "grade": "3학년", "date": "2025년 11월 20일 3교시" },
  "questions": [
    {
      "stem": "다음은 우무를 이용한 실험을 나타낸 것이다.",
      "image": { "path": "그림/1번.png", "widthMm": 60 },          // 선택
      "passage": { "title": "", "lines": ["[실험 과정]", "(가) …"] }, // 자료 상자(선택)
      "stemAfter": "이에 대한 설명으로 옳은 것만을 <보기>에서 있는 대로 고른 것은?", // 그림·자료 뒤 발문(선택)
      "points": 4,
      "box": { "lines": ["A보다 B가 …", "세포 분열이 …"] },         // <보기>: ㄱ. 은 안 적어도 됨
      "choices": ["ㄴ", "ㄷ", "ㄱ, ㄴ", "ㄱ, ㄷ", "ㄱ, ㄴ, ㄷ"],      // ①② 기호는 자동
      "answer": [1],
      "explanation": "해설(정답지에 들어감)"
    },
    { "group": { "count": 2, "text": "공통 지문" }, "stem": "…", "points": 4, "choices": ["…"], "answer": [5] }
  ]
}
```

| 글 안 표기 | 결과 |
|---|---|
| `$E = {1} over {2} mv^2$` | 한글 수식 |
| `**않는**` / `__㉠__` | 굵게 / 밑줄 |
| 줄바꿈 `\n` | 같은 문단 안 줄 나눔 |

## 기본 양식 (`-t` 없이 출력할 때)

학교 양식이 없으면 내장 **표준 양식**(`forms/default`)을 씁니다. 학교 양식과 똑같은 방식으로 만들어져 있어서
스타일(문항, 이어지는 발문, 선택지 자동번호, 선택지 1행/2행/3행, 보기, 자료, 그림, 묶음 문항)과
개요 번호(1. → ① → ㄱ.)가 갖춰져 있고, 출력한 뒤 스타일만 고치면 전체가 바뀝니다.

표준 양식을 고쳐 다시 만들려면(한글 필요): `testmaker build-default-form forms/default`
