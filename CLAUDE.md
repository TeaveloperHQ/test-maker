# Test Maker

Exam-paper generator for Korean teachers. Goal: every school's 시험지 양식 differs; questions are authored style-free (JSON) and converted to the school's own style. User-facing docs: README.md (Korean).

## Architecture (school forms = clone the school's own prototypes)
- `src/TestMaker.Core/Forms` (pure XML, no 한글):
  - `FormLearner` — classifies top-level paragraphs into roles (Stem, StemCont, GroupHeader, Figure, ViewBox, PassageBox, Choice, Spacer). Stems = paragraphs whose paraPr heading is OUTLINE/NUMBER level 0 (완성형); else typed "1." sequence (무질서형). Primary doc (school 양식 file) supplies styles/boxes/choice layouts; `--also` docs (real exams) supply usage stats (spacer count, most-used style *names*, observed para shapes). Writes form dir: `form.json` (ExamForm), `base.hwpx` (header + preamble + `{{문항}}` marker paragraph + tail), `boxes.xml` (box table prototypes).
  - `FormAssembler` — copies base.hwpx, replaces marker paragraph with generated paragraphs referencing school style/paraPr/charPr ids; inline bold/underline via `HeaderInfo.CharVariant`; 원안지 answers wrapped in `hp:markpenBegin/End`; equations/images left as `#EQ001#`/`#IMG001#` placeholders.
  - `HeaderInfo` — header.xml lookups + additive edits (char variants, unnumbered/indent-aligned para variants, importing para shape values from another doc). Never renumber existing ids.
- `src/TestMaker.Hwp/FormRendering` — COM only for: .hwp→.hwpx normalization before learning, filling placeholders (RepeatFind → Delete → EquationCreate/InsertPicture), page-count pass for `{{쪽수}}`, SaveAs hwp/hwpx/pdf.
- Standard form (user decision 2026-10-16: B4 2단, 한양신명조 11pt, everything via styles so schools swap fonts in styles, 학교 지필평가형 preamble; school preambles are learned). The builder also writes the distributable `forms/표준 시험지 양식(B4).hwp` with tokens replaced by ○ placeholders.
- Built-in default form `forms/default` (copied next to the exe via TestMaker.Hwp.csproj): generated by `Hwp/DefaultFormBuilder` (`testmaker build-default-form forms/default`) — injects styles/numbering/tab stops into a blank doc via `HeaderInfo.Add*`, writes sample questions in 한글 with those styles, then runs `FormLearner` on it. So the default path is the same clone-and-fill pipeline as school forms. Regenerate and commit it after changing the builder.
- `Templates/Styles.cs` (TextStyle/ParaStyle/PageProfile…) + `HwpWriter` direct formatting are only for the builder, preamble of the standard form, and the answer sheet.
- Authoring (user decision 2026-10-21: questions come mainly from reference material; engine = the teacher's installed Claude Code, not an API key; UI = WPF):
  - `src/TestMaker.Ai` (no 한글): `ClaudeCode` runs `claude -p --output-format stream-json --restricted --tools Read,Write,Edit,Glob,Grep,PowerShell` in the job dir (strips `CLAUDECODE` env so it works when launched from a Claude Code session); tool calls → Korean progress lines. `Authoring` = job folder (`job.json`, `sources/`, `items/qNN.json`, `figures/`): AddSource (copies; hwp → `HwpSource.Convert` → PDF + BinData images), FindQuestionsAsync (Claude writes `found.json`), MakeVariantsAsync (Claude writes `items/qNN.json` in the Exam/Question schema; app checks count/ExamValidator/figure files and resumes the same session up to 2× to fix), BuildExam. Contract with Claude is always files, never parsed chat text. `Prompts` holds the instructions — the figure rule (copy the original as identically as possible; crop it if unchanged; .ps1 with UTF-8 BOM) is the user's.
  - `src/TestMaker.App`: one window, ① 자료 (drop/Ctrl+V/hwp) → ② 문항 표 (사용/원문항/변형 방식/변형 수, per question) → ③ 결과 확인·보관 → ④ 시험지. Under `Documents\TestMaker` (override `TESTMAKER_HOME` for tests — never test against the teacher's real folders): `작업`, `양식`, `문항함`, `시험지`. `TestMaker.exe <jobDir>` opens a job; `TESTMAKER_SNAPSHOT=x.png` (+ `TESTMAKER_SNAPSHOT_BANK=y.png`) renders the windows to PNGs and exits (verify UI without screen capture — never screen-capture the user's desktop).
  - 작업 = named profile per exam (user decision 2026-10-22, e.g. "2026 2학기 1차고사"): `Authoring.Create/List`, folder = sanitized name. job.json persists everything shown — sources, questions (style/variants), `Excluded` (③ unchecked), `Archived`, `ExamList` (④ keys + order; bank entries by `BankDir`), Info, FormDir, Pdf/Answers — saved on every change (`loading` flag suppresses saves while `ShowJob` restores). Last job reopens at start (`<Home>/settings.json`). Exams render into `<job>/시험지/<date time>/`. `Authoring` works without Claude (only find/make throw).
  - 문항함 (user decision 2026-10-21): `Core/Bank/QuestionBank` — one folder per question under `시험용`/`예상문제` (`item.json` = BankItem + copied figure), no index file (folder is truth). ④ is filled automatically from ③'s checked results ("바로 만들면 그대로"); bank items are added via BankWindow; `QuestionBank.Absolutize` makes figure paths absolute so mixed sources render together. `AuthoringJob.Archived` prevents double-archiving.
  - Equations: Claude must brace fractions and write whole expressions as one `$…$`; `InlineMarkup.GluedEquations` (ExamValidator warning, incl. explanations) feeds the fix loop; previews use `InlineMarkup.ToPlain`.
  - `testmaker author <jobDir> <files…> [-n] [--keep] [--style]` runs the whole pipeline headless.

## School conventions learned so far (the user's own school; sample paths are in local memory, never in the repo)
- Outline numbering 1. → ① → ㄱ. ; 5행 choices use auto numbering, 1/2/3행 choices typed ①…⑤ with tabs (user rule).
- `<보 기>` box = 3×3 table, content in merged bottom cell; lines use style "박스 ㄱㄴㄷ" (auto ㄱ.).
- Continuation stems: same style with numbering off; align under stem text via `HeaderInfo.AlignUnder` (stem uses left 0 + negative intent hanging).
- Fill-in fields in the form are blue text → auto-tokenized at learn time.

## HWPX / 한글 facts (verified on 한컴오피스 2024 Edu — re-measure before "fixing")
- COM `HStyle.Apply = n` uses the header style id. Applying a numbered style yields auto numbers; injected styles/numberings in header.xml are accepted.
- Para margins: COM value == `<hp:default>` value == 2× `<hp:case>` value. Text color HWPX `#RRGGBB`, COM BGR via `RGBColor`.
- Assembled XML opens fine with `id="0"` paragraphs and stripped `linesegarray` (한글 re-layouts). `<hp:tab>` width attrs are recomputed.
- Re-saving base.hwpx through 한글 may renumber header ids → never re-save the learned base.
- Tab stops (`hh:tabItem pos`, `<hp:case>` = real HWPUNIT) are measured from the column's left edge, NOT the paragraph's left margin.
- Numbered paragraphs: set numbering `paraHead autoIndent="0"` (as school forms do); then the number sits at the paragraph's left margin, a negative `intent` makes wrapped lines hang under the text. With autoIndent=1 the indent is applied twice.
- Choice-layout fit: needed = (longest + "① " 1.5em + 1em gap) × em; slot = (column − choice left margin) / per-line.
- Typed choice lines: tab count is computed per gap (slot targets vs. paraPr tab stops, then secPr `tabStopVal` default interval). Never copy the prototype's tab counts — schools tune them for 1-2 char choices.
- Password-protected .hwp (FileHeader props bit1; school 원안지 often are): 한글 shows a password dialog that hangs a hidden instance. `HwpFileInfo` pre-checks; `Open` passes `suspendpassword:true`.
- After `Quit`, Hwp.exe lingers briefly; a new session can attach to it and abort. `HwpSession.Dispose` waits for its own process to exit.
- Forms may number several question types at level 0 (선택형 "1." + 논술형 "논술형 1>"): only the most-used numbering is treated as stems; others are block boundaries.
- Boxes cloned from real exams may have fixed tall rows (they held figures): `ShrinkRow` resets the content row height.
- **Security prompt**: when automation opens/saves a file outside `%TEMP%`, 한글 shows "한글을 이용하여 위 파일에 접근하려는 시도… 접근 허용?" → hidden instance hangs. `HwpSession.Open/SaveAs` always route through a session temp dir and copy with .NET. Never call `hwp.Open/SaveAs` with user paths directly.
- **Never apply styles via COM** (`HAction "Style"`): it intermittently opens the 스타일 dialog → hang. The builder writes `§id§` tags (`StyleTags`) and assigns styles in XML. Don't put a tag right before `TableCreate` — 한글 splits the table into its own paragraph (blank line + unstyled box); style box paragraphs in XML instead.
- COM-created tables save `<hp:sz width="0">` (use cellSz widths) and `horzRelTo="COLUMN"` (ignores paragraph margin — set `PARA` to indent boxes under stem text).
- Essays (서술형/논술형): learned from level-0 paragraphs whose numbering text contains 서술/논술 (`ExamForm.Essay`, boxes `essayHeader`/`condition`/`answerLine`). With an essay proto, essays are numbered separately; without, they continue the MC numbering. `<조 건>` falls back to the 보기 box with the title replaced and ㄱ. numbering removed.
- `<보 기>` title-on-border box = 3×3 table built in XML (`ViewBoxShape`); `ContentCell` picks the widest cell (paragraph count picks the title cell for 1-line 보기).
- Diagnosing hangs: `TESTMAKER_TRACE=1` traces HwpWriter calls; read dialog text of the hung Hwp.exe with UI Automation (`AutomationElement` by ProcessId).
- COM session: abort if attached to the user's open 한글; dispose always (unhandled exceptions skip finally → leaked Hwp.exe).
- COM-typing gotchas (builder/answer sheet): `BreakColDef` + MultiColumn `ApplyTo=2`; table ColWidth excludes 3.6mm cell padding; 한글 appends an empty paragraph after a table at doc end; tab stops via COM `TabDef` render inconsistently; `CreateItemArray` returns null in C# (set `Item` via reflection).

- Windows PowerShell 5.1 reads BOM-less UTF-8 as ANSI: `.ps1` scripts with Korean need a BOM, and never round-trip source files through `Get-Content`/`Set-Content` (use the Edit tool).

## Conventions
- User-facing strings/comments in Korean, actionable for teachers.
- Never modify user-supplied files; work on temp copies. Don't commit school files; real-form tests use `TESTMAKER_SCHOOL_FORM`/`TESTMAKER_SCHOOL_EXAM`.
- Verify layout changes visually: render with `--pdf` and read the PDF.
